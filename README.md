agent in a recorded session for the $500 "Bring the humans with a TikTok ad"
bounty. The video is posted publicly on TikTok from `@oblong1234561`;
`VIDEO.json` holds its full address.

The entrypoint `main.ts` (Node 22) copies `VIDEO.json` into the grader's
`/output` directory. Run it locally with:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

The house reads the video itself and ranks it by views.
